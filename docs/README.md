# OctoAcme Project Management Docs

This folder contains OctoAcme’s project management processes and role guidance. The docs are intended to provide a shared, practical reference for delivering cross-functional projects and onboarding team members.

## Process summary

OctoAcme manages projects through a lightweight lifecycle: initiation, planning, iterative execution, release, and closeout with a retrospective. Initiation validates the business need, identifies stakeholders, defines measurable success criteria, and creates a project one-pager with an initial timeline, risks, and resource needs. Planning turns approved work into prioritized, estimated backlog items with acceptance criteria, a Definition of Done, dependency mapping, milestones, and a release plan.

Teams track delivery on a project board and aim for small, reviewable pull requests linked to issues and acceptance criteria. Project Managers coordinate schedules, risks, dependencies, and communications; Product Managers define outcomes, prioritize the backlog, and measure success; developers implement and test the work; QA validates quality and acceptance; and stakeholders provide input and approvals.

Communication includes regular delivery standups, weekly PM and Product Manager alignment, delivery updates and demos, and regular stakeholder updates. Risks are recorded with impact, likelihood, owner, mitigation, and status, reviewed regularly, and escalated through the PM, Product Lead, and sponsor as appropriate. A shared project README or release document serves as the source of truth for status.

Quality assurance is integrated throughout delivery: unit tests for new logic, integration tests where applicable, smoke tests for critical flows, CI tests and linting, security scanning, and manual QA when needed. Releases require acceptance criteria and readiness checks, release notes, smoke tests, and a rollback or mitigation plan. Retrospectives after sprints, releases, milestones, or incidents capture learnings and track a small set of owned improvement actions.
